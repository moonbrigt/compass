# 工作流 6：任务管理

视频：14:11–16:42。每项任务都应能快速返回解释它为何存在的上下文。

## 组成部分

| 部分 | 在本仓库中的位置 |
| --- | --- |
| Tasks 插件与行内任务 | 任意笔记中的 `- [ ]`；可用 📅 截止、⏳ 安排、🔁 重复、⏫ 优先级 |
| 任务总表 | `08 任务/任务总表.md`，由 QuickAdd 的“✅ 添加任务（任务总表）”写入 |
| 项目归属 | `#project/<slug>`，由项目笔记中的查询收集 |
| 人物任务 | `05 人物/` 与 `模板/人物.md`，使用 `#p/<slug>` |
| 待讨论事项 | 同时带 `#discuss #p/<slug>` 的任务会显示在该人物笔记及任务仪表盘 |
| 任务仪表盘 | `00 仪表盘/任务仪表盘.md`：逾期、今天、未来 7 天、待讨论、无日期高优先级、收件箱、本周完成 |

`slug` 由笔记标题转为小写，并把不适合标签的字符变成连字符；项目与人物模板会在笔记顶部列出实际生成的标签。中文标题会保留汉字。

## 执行方式

仪表盘给出建议。从中选择今天要做的任务，再在日历或纸上划出执行时间。仓库存放任务与上下文，不代替你安排当天的时间。

## 适用边界

地点提醒、许多带服务期限的客户项目或团队共用任务，需要对应的专用工具。任务总表适合先捕获再整理：真正的截止事项才设置截止日期；一般任务可以没有日期，只用标签关联项目或人物。开会前读人物笔记，会后在会谈记录里留一行。
