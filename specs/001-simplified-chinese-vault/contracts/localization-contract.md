# Localization Contract

## 保持不变的标识

- `元数据/Compass 配置.md` 的机器属性键及 `dq_`、`habit_`、`wheel_` 前缀。
- 属性键及 wikilink 的语义目标。首方内容目录和用户可见文件名按迁移表改为中文，必须同步更新链接、嵌入及全部路径消费者。
- `life-os-app`、QuickAdd 等插件 ID、命令 ID、选项 `id` 和 CSS 类名。Dataview 视图路径与目录一起迁移。
- Templater 的 `<% ... %>`、QuickAdd 占位符语法及修饰符、日期格式串、代码围栏语言和 YAML 键。八个新建笔记选项中独立使用的 `VALUE` 交互变量与 `label:` 提示同步翻译；其余变量和命令标识保留。
- `#example` 等用于筛选数据的标签与任务格式符号。

## 可翻译的值

- Markdown 正文、标题、表格标签、引用说明、模板生成的段落提示。
- 首方 Life OS 的导航、按钮、说明、状态、空状态、错误和确认文案。
- 仪表盘图表标题、表头、提示以及 QuickAdd 选项的显示名称。
- 配置中的问题、习惯、生活领域等自然语言显示值。

## 例外

许可证原文、第三方插件分发文件、命令等技术标识、原文引用、书名、人名及产品名可保留原文。`.obsidian/`、`scripts/`、`wiki/`、`inbox/` 是现有工具约定的技术目录。保留项要在覆盖审计中可识别，不得作为遗漏隐藏。

## 验证契约

从固定的上游基线提交对比机器标识，并按目录及文件迁移表检查每个旧路径的消费者；从本分支审计可翻译文案；构建候选仓库并检查内链、模板、脚本和原生界面。任何有意改变的稳定标识必须先列入计划并更新全部引用。
