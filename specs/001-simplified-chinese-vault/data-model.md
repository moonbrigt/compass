# Data Model: 汉化内容与稳定标识

## 文案单元

- **来源**: 一个首方界面字符串、仪表盘标签、Markdown 段落、模板提示或配置显示名。
- **上下文**: 文件路径、位置、用户动作和关联工作流。
- **译文**: 简体中文自然语言，保留原意及权限限制。
- **状态**: 已翻译、保留原文（专有名称/技术标识/引用）、待处理。
- **验证**: 静态审计与对应 Obsidian 界面或生成结果。

一个来源只对应一个最终显示译文；同一概念可在多个来源出现，使用术语表统一用词。

## 稳定标识

- **路径和内部链接**: 笔记、模板及视图的定位依据，默认保持英文规范化名称。
- **属性键与标签**: `dq_*`、`habit_*`、`wheel_*`、`example` 等由脚本读取，值中的显示文本可翻译。
- **命令标识**: `life-os-app:*`、`quickadd:choice:*` 等由插件调用，ID 不翻译。
- **模板表达式**: Templater、QuickAdd 和日期格式表达式保持可执行。

## 生成关系

`scripts/template/defaults/` 会覆盖或恢复若干笔记；QuickAdd 和 Templater 会生成用户笔记；`元数据/视图/` 从属性与现有笔记生成仪表盘；Life OS 读取同一批笔记与命令。因此译文必须在各生成来源同步更新，不能只改最终页面。
